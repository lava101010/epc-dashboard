========================================================
  ابدأ من هنا — خريطة المشروع في دقيقة
========================================================

تخيل 3 أوض:

 1) الورشة (المصنع):  index.html + css/ + js/ + tools/
    → الخام والكود. متفتحهاش ومتبعتهاش لحد.
      السكريبتات بتقرأ منها عشان تصنع المنتج.

 2) المنتج النهائي:  dist/
    → اللي اتبنى بداتا يومك.
    → dist/standalone.html = الداشبورد في ملف واحد:
      ده اللي تفتحه انت / تبعته واتساب / تحفظه.

 3) واجهة العرض:  docs/
    → نسخة أوتوماتيك من dist بيقرأها GitHub عشان
      يعمل الرابط العام (Pages). بتتحدث لوحدها — متلمسهاش.

(يعني index.html و dist و docs مش 3 مشاريع —
 ده نفس الداشبورد في 3 مراحل: خامة → منتج → معروض)

========================================================
 اللي تمسكه بإيدك — 3 حاجات بس طول عمرك
========================================================
 • incoming/     ← ترمي فيه ملف الـ ERP كل يوم وتخلص.
                    المراقب التلقائي يعمل الباقي كله.
 • publish.bat   ← دبل كليك لو عايز تحديث + رفع يدوي مرة.
 • plan.json     ← تعدل أرقام خطة الشهر أول كل شهر.
 (+ EPC-Interactive-Dashboard.xlsx لو عايز تفتح الإكسيل)

========================================================
 ملفات tools (الـ .py) — انت مش هتشغلها أبداً
========================================================
 • update_dashboard.py ← المحرك: يبني dist وdocs من ملف الـ ERP
                         (بيشتغل من الـ bat أو من المراقب)
 • auto_update.py      ← الغفير: يراقب incoming كل 60 ثانية
                         ويستدعي المحرك + يعمل commit + push
                         (ويندوز يشغله لوحده مع كل دخول)
 • gen_excel.py        ← مصنع الإكسيل (الغفير يستدعيه)
 • tests/ layout_check.py ← عدة فحص جودة للمطور — انسها

========================================================
 خلاصة اليوم العادي
========================================================
   تصدّر من الـ ERP → تحط الملف في incoming/ → تقفل الموضوع.
   (ولو نسيت يوم: حطه أي وقت — كله بيتلحق لوحده)

 لو ضعت تاني: افتح الملف ده وقرا العشر سطر اللي فوق بس.

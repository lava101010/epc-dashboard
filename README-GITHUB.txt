========================================================
  النشر على GitHub (+ رابط عام عبر GitHub Pages)
========================================================

■ مرة واحدة بس: إنشاء الريبو وربطه
========================================================
1) github.com → سجل دخول / حساب جديد
2) زرار + فوق → New repository
   • الاسم: epc-dashboard
   • الخصوصية: Private إذا كان عندك خطة Team/Enterprise،
     أو Public لو عايز رابط Pages مجاني (شوف التحذير تحت)
   • متضفش README ولا .gitignore (إحنا عندنا بالفعل)
   → Create repository
3) على جهازك، جوّه فولدر المشروع، افتح Command Prompt:
       git remote add origin https://github.com/USERNAME/epc-dashboard.git
       git push -u origin main
   (أول مرة هيفتحلك المتصفح تسجل دخول وتوافق — وبعدها الويندوز
    بيحفظ الدخول ومبيسألش تاني)
4) خلاص — الريبو فيه مشروعك كله، وأي تحديث جديد هيترفع لوحده.

■ رابط عام عبر GitHub Pages (اختياري)
========================================================
1) في الريبو: Settings → Pages
2) Source: Deploy from a branch
3) Branch: main   Folder: /docs   → Save
4) بعد دقيقة: لينكك يبقى
       https://USERNAME.github.io/epc-dashboard/
   (فولدر docs بيتولد ويتحدث أوتوماتيك مع كل بناء — متلمسوش)

⚠️ تحذير مهم قبل ما تختار Public:
   GitHub Pages المجانية بتشتغل بس مع الريبوهات العامة —
   يعني كل اللي في الريبو (ومنه بيانات الإنتاج في docs/)
   يبقى متاح لأي حد على النت.
   • بياناتكم سرية؟ → خلّي الريبو Private واستخدم
     standalone.html للإرسال، أو اسأل الـ IT عندكم عن خطة
     Team/Enterprise (بتفتح Pages للخاص).
   • مش سرية؟ → Public عادي وخد رابط Pages.

■ اليوم وبعد كده: مفيش خطوات
========================================================
• حط ملف الـ ERP في incoming/ → المراقب التلقائي يبني
  ويرفع (commit + push) لوحده → رابط Pages يتحدث في دقيقة.
• أو دبل كليك publish.bat يعمل نفس الحاجة يدوياً.
• لو الـ push وقف يسأل عن دخول: افتح cmd مرة واحدة واعمل
  push يدوي وسجل الدخول، وبعدها كله يرجع أوتوماتيك.

■ أسئلة سريعة
========================================================
س: حد يقدر يعدل الريبو؟
ج: لأ — الكتابة لحسابك بس. اللي فاتحه الرابط العام بيشوف
   قراءة فقط، والنسخة الرسمية دايماً اللي انت ناشرها.
س: بصمة التحقق لسه شغالة؟
ج: أيوة — أسفل الداشبورد: آخر تحديث + البصمة، وأي نسخة
   معدّلة أو قديمة تتفضح بمقارنة البصمة.
س: عايز أرجع لنسخة قديمة؟
ج: تاريخ الـ commits على GitHub فيه كل نسخة يومية —
   تقدر تستعرضها أو ترجع لها في ضغطة.

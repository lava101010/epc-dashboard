========================================================
  التحديث التلقائي اليومي — من غير ما تعمل أي حاجة
========================================================

■ الفكرة
========================================================
عندك فولدر اسمه  incoming/  جوّه فولدر المشروع.
كل يوم: صدّر ملف الـ ERP (0040_qa.xls) واحفظه أو اسحبه فيه.
المراقب التلقائي هيلاقيه في خلال 60 ثانية كحد أقصى ويعمل لوحده:
   1) يبنى الداشبورد من الملف الجديد (dist/ + standalone.html)
   2) يحدّث الإكسيل التفاعلي (EPC-Interactive-Dashboard.xlsx)
   3) يرفع على GitHub (commit + push — ورابط Pages يتحدث لوحده)
   4) ينقل الملف اللي اتعالج لـ incoming/processed/ (أرشيف)
   5) يكتب سجل كل عملية في tools/auto_update.log

الملف تراكمي (كل يوم بيزيد سطور اليوم)؟ ممتاز — ده بالظبط
اللي السكريبت متصمم له: بيبني من الملف كله في كل مرة.

■ التشغيل مرة واحدة (وبس) — من غير أي تنصيب
(بايثون والمكتبات موجودين جوّه المشروع في tools\python)
========================================================
افتح Command Prompt والصق الأمر ده (عدّل المسار C:\EPC لمسارك):

   schtasks /create /tn "EPC Auto Update" /tr "\"C:\EPC\tools\python\pythonw.exe\" \"C:\EPC\tools\auto_update.py\" --loop" /sc onlogon

معناه: مع كل تسجيل دخول لويندوز، المراقب بيشتغل في الخلفية
(من غير نافذة) ويفضل يراقب فولدر incoming/ طول اليوم.

■ لو عايز تحديث لحظي بدون انتظار الـ 60 ثانية
========================================================
دبل كليك على tools/auto_update.py  (أو من cmd):
   python tools\auto_update.py
بيعمل فحص واحد فوري وينفذ لو فيه ملف جديد.

■ النشر الأونلاين (GitHub) — إعداد مرة واحدة
========================================================
أول مرة بس: اربط الريبو (التفاصيل في README-GITHUB.txt):
   git remote add origin https://github.com/USERNAME/REPO.git
   git push -u origin main
من بعدها: كل تحديث جديد بيعمل commit + push لوحده،
ورابط GitHub Pages بيتحدث في حوالي دقيقة.
لو مفيش ريبو مربوط — المراقب بيحدّث الملفات المحلية
ويسجل في اللوج إن الـ push اتعدى.

■ أسئلة متوقعة
========================================================
س: نسيت أنقل الملف يوم؟
ج: لما تنقله أي وقت — المراقب هيالتقطه ويعمل كل حاجة،
   مش مهم الساعة كام.
س: حطيت ملف بالغلط؟
ج: لو البناء فشل هتلاقي "BUILD FAILED" في اللوج والملف
   هيفضل في incoming/ — صلّح الملف أو امسحه والمراقب يكمل.
س: الشهر خلص وبدأ شهر جديد؟
ج: عدّل أرقام plan.json بس (أو سجلها من زرار 🎯 في الداشبورد)
   والملف الجديد الشهر بيتعرف تلقائياً والشهر القديم بيتأرشف.
س: أوقف المراقب إزاي؟
ج:  schtasks /delete /tn "EPC Auto Update" /f
